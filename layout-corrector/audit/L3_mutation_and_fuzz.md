# L3. Reference engine: mutation testing, invariants, fuzzing

Status of this report: `REFERENCE_VERIFIED` for the properties of the reference **algorithm**. It says nothing about delivery of
physical events by a real hook or Raw Input (that needs `INTEGRATION_VERIFIED`, plan v1.2 item Q-7).

## What was run

* Tool: `audit/L3/mutate.py` (standard library only), driver `audit/L3/resume_run.py` (resumable, 2 workers).
* Mutated file: `reference/lfengine.py` from line 173 (`# ==== 20.5`) to the end, 659 single-point mutants, six operators:
  comparison swap, boolean swap, integer literal ±1, float literal ×2 and ÷2, statement deletion, True/False swap.
  All 659 compile; all were run (no sampling).
* Oracle for each mutant: `conformance.py 20000` (property, negative, boundary and fault-injection tests). Survivors also get
  `vectors.py` against `vectors_out.json` and `test_ref.py`.
* Raw results: `audit/L3/results.json`; the generated listing is `audit/L3/L3_mutation_report.md`.
* Reproduce: copy `reference/` to a folder with the mutants generated by `python3 mutate.py gen`, then `python3 resume_run.py 480`
  until it prints `results.json written`, then `python3 mutate.py report`.

## Invariants and fuzzing

`conformance.py` checks, on every case, the invariants of plan section L3 (I1 to I6): no key lost or duplicated by the engine,
`convert` only at `s ≥ λ` with gate ALLOW, word length at most 20 keys or reset, snapshot lifetime at most 10 s and 100
characters, no snapshot after a context break, gate change or layout change, and undo equal to the recorded keys rendered with
the recorded layout. The run used `N = 200000` events per group (the full audit run uses 10⁶) and 387 single and double faults of the
replacement transaction, 60 fuzz conversions and 40 fuzz undos.

## Limits

* The mutants cover the engine from section 20.5 on; tables and rendering (20.2 to 20.4) are covered by the vectors and by the
  independent re-implementation (line L1).
* Operators are first-order; combinations of two defects were not generated.
* An equivalence argument is an argument, not a proof; each can be re-checked by running the file `m/<id>/lfengine.py`.
