# Punto Tests

Комплексный набор тестов для проекта Punto.

## 📦 Структура тестов

```
tests/
├── test_unit.py         # Unit-тесты базовой логики
├── test_integration.py  # Интеграционные тесты
├── test_quality.py      # Тесты качества распознавания
└── test_stress.py       # Стресс-тесты и производительность
```

## 🧪 Типы тестов

### 1. Unit-тесты (`test_unit.py`)
Тестирование базовой логики без зависимостей:
- ✅ Конвертация между раскладками (en ↔ ru)
- ✅ Сохранение регистра символов
- ✅ Обработка спецсимволов
- ✅ Короткие слова (SHORT_EN, SHORT_RU)
- ✅ Загрузка словарей

### 2. Интеграционные тесты (`test_integration.py`)
Проверка реальной работы компонентов:
- ✅ Запуск punto без ошибок
- ✅ Загрузка словарей (93K+ en, 1.1M+ ru слов)
- ✅ Определение текущей раскладки
- ✅ Отсутствие утечек памяти (< 1MB на 10K операций)
- ✅ Thread-safety (параллельные конвертации)
- ✅ Обработка граничных случаев (пустая строка, один символ, unicode, emoji)

### 3. Тесты качества (`test_quality.py`)
Точность распознавания слов:
- ✅ Частые русские слова (привет, пока, работает...)
- ✅ Частые английские слова (hello, working, github...)
- ✅ Короткие слова (am, is, да, не...)
- ✅ Целые предложения
- ✅ Общая точность ≥ 90%

### 4. Стресс-тесты (`test_stress.py`)
Стабильность под нагрузкой:
- ✅ 1000+ последовательных конвертаций
- ✅ Быстрый ввод (1ms интервалы)
- ✅ Параллельная обработка (20 потоков)
- ✅ Длинные тексты (10K+ слов)
- ✅ Стабильность памяти (< 5MB на 1K операций)
- ✅ Производительность ≥ 1000 конв/сек
- ✅ Восстановление после ошибок

## 🚀 Запуск тестов

### Локально

```bash
# Установить зависимости
pip install pytest pytest-cov pytest-timeout

# Запустить все тесты
pytest tests/ -v

# Запустить конкретный набор
pytest tests/test_unit.py -v
pytest tests/test_quality.py -v
pytest tests/test_stress.py -v

# С coverage
pytest tests/ --cov=. --cov-report=html
open htmlcov/index.html
```

### GitHub Actions

Тесты запускаются автоматически при:
- Push в `main` или `develop`
- Pull Request в `main`

**Матрица тестирования:**
- macOS: 13, 14
- Python: 3.10, 3.11, 3.12, 3.13

**Jobs:**
1. **test** - Все наборы тестов (unit, integration, quality, stress)
2. **lint** - Проверка кода (flake8)
3. **performance** - Бенчмарки производительности (≥1000 конв/сек)

## 🐛 Обнаруженные баги

Тесты помогают выявить:

### Критические баги:
- ❌ `NameError: SHORT_EN not defined` - падение при обработке коротких слов
  - **Причина:** Старый .pyc кэш
  - **Решение:** Очистка `__pycache__` и .pyc файлов

- ❌ Двойное срабатывание исправлений
  - **Причина:** Конфликт нескольких процессов punto
  - **Решение:** Запуск только одного процесса через LaunchAgent

- ❌ Съедание пробелов и склеивание слов
  - **Причина:** Повторные исправления удаляют лишние символы
  - **Решение:** Предотвращение конфликтов процессов

### Проблемы с permissions:
- ❌ Punto не перехватывает события после нескольких часов работы
  - **Причина:** Accessibility permissions для Terminal, а не для Python.app
  - **Решение:** Добавить `/Library/Frameworks/Python.framework/.../Python.app` в Accessibility

## 🔧 Отладка

### Проверка логов
```bash
tail -f ~/punto/punto.log          # Основной лог
tail -f ~/punto/punto.err.log      # Ошибки
```

### Проверка процессов
```bash
ps aux | grep punto                # Punto процессы
launchctl list | grep punto        # LaunchAgent статус
```

### Очистка кэша
```bash
cd ~/punto
find . -name "*.pyc" -delete
find . -name "__pycache__" -type d -exec rm -rf {} +
launchctl unload ~/Library/LaunchAgents/com.user.punto.plist
launchctl load ~/Library/LaunchAgents/com.user.punto.plist
```
