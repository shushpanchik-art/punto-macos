# Punto Switcher для macOS

Автоматический переключатель раскладки клавиатуры для macOS, аналог Punto Switcher для Windows.

## Возможности

- **Автоматическое исправление**: При нажатии пробела слово, набранное в неправильной раскладке, автоматически исправляется
- **Ручное исправление**: Двойной Shift или Control + Option + Z для исправления последнего слова
- **Словари**: Использует словари английского и русского языков для определения правильной раскладки
- **Исключения**: Поддержка списка слов, которые не нужно исправлять

## Горячие клавиши

- **Двойной Shift** (быстро нажать и отпустить Shift два раза) — исправить последнее слово
- **Control + Option + Z** — исправить последнее слово
- **Control + Option + P** — включить/выключить автоматический режим

## Установка

```bash
bash setup.sh
```

После установки нужно выдать разрешения в Системных настройках:
- **Конфиденциальность и безопасность → Мониторинг ввода** — добавьте Terminal или Python
- **Конфиденциальность и безопасность → Универсальный доступ** — добавьте Terminal или Python

Затем перезапустите службу:
```bash
launchctl unload ~/Library/LaunchAgents/com.user.punto.plist
launchctl load ~/Library/LaunchAgents/com.user.punto.plist
```

## Файлы

- `punto.py` — основной скрипт
- `words_en.txt` — словарь английских слов
- `words_ru.txt` — словарь русских слов
- `exceptions.txt` — слова-исключения, которые программа не трогает
- `punto.log` — журнал исправлений

## Требования

- macOS
- Python 3.7+
- Библиотеки: pynput, pyobjc
