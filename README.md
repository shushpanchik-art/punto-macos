# Punto Switcher для macOS

Автоматический переключатель раскладки клавиатуры для macOS, аналог Punto Switcher для Windows.

## Возможности

- **Автоматическое исправление**: При нажатии пробела слово, набранное в неправильной раскладке, автоматически исправляется
- **Ручное исправление**: Двойной Shift или Control + Option + Z для исправления последнего слова
- **Словари**: Использует словари английского и русского языков для определения правильной раскладки
- **Исключения**: Поддержка списка слов, которые не нужно исправлять
- **Несколько версий**: От базовой до оптимизированных с LLM

## Версии

### punto.py (Базовая)
Стабильная версия с полной функциональностью. Рекомендуется для большинства пользователей.
- ✅ Полная функциональность
- ✅ Словари 93K (EN) + 1.1M (RU) слов
- ✅ Двойной Shift и горячие клавиши
- ✅ Автоматический режим

### punto_fast.py (Быстрая)
Оптимизированная версия с кэшированием для ускорения проверок.
- ⚡ LRU-кэш для 10K последних проверок
- ⚡ Ограничение длины слова (макс 15 символов)
- ✅ Все функции базовой версии

### punto_ultimate.py (Максимальная)
Баланс скорости и качества с большим кэшем.
- ⚡ Огромный LRU-кэш (100K записей)
- ⚡ Максимальная длина слова (20 символов)
- ✅ Оптимальные настройки для интенсивной работы

### punto_hybrid.py (Гибридная)
Комбинация быстрых проверок и словарей.
- 🎯 Умные эвристики для коротких слов
- 🎯 Быстрая предварительная фильтрация
- ✅ Балансирует скорость и точность

### punto_llm.py (Экспериментальная)
Использует легкую LLM (TinyLlama/Ollama) вместо словарей для определения языка.
- 🤖 AI-определение языка
- 🔧 Требует установки Ollama
- 🧪 Экспериментальная версия

## Горячие клавиши

- **Двойной Shift** (быстро нажать и отпустить Shift два раза) — исправить последнее слово
- **Control + Option + Z** — исправить последнее слово
- **Control + Option + P** — включить/выключить автоматический режим

## Установка

```bash
bash setup.sh
```

После установки нужно выдать разрешения в Системных настройках:
- **Конфиденциальность и безопасность → Мониторинг ввода** — добавьте Terminal или Python
- **Конфиденциальность и безопасность → Универсальный доступ** — добавьте Terminal или Python

Затем перезапустите службу:
```bash
launchctl unload ~/Library/LaunchAgents/com.user.punto.plist
launchctl load ~/Library/LaunchAgents/com.user.punto.plist
```

## Диагностика

Если что-то не работает, запустите диагностику:
```bash
python3 diagnostics.py
```

Это проверит:
- ✅ Версию Python и установленные библиотеки
- ✅ Разрешения Accessibility
- ✅ События клавиатуры

## Тестирование

Запустите smoke тесты для проверки всех функций:
```bash
python3 smoke_test.py
```

Или модульные тесты:
```bash
python3 test_punto.py
```

## Файлы

- `punto.py` — основной скрипт (рекомендуется)
- `punto_fast.py` — быстрая версия с кэшированием
- `punto_ultimate.py` — максимальная производительность
- `punto_hybrid.py` — гибридная версия
- `punto_llm.py` — экспериментальная версия с LLM
- `words_en.txt` — словарь английских слов (93K)
- `words_ru.txt` — словарь русских слов (1.1M)
- `exceptions.txt` — слова-исключения, которые программа не трогает
- `punto.log` — журнал исправлений
- `diagnostics.py` — диагностика системы
- `smoke_test.py` — автоматические тесты
- `test_punto.py` — модульные тесты

## Требования

- macOS
- Python 3.7+
- Библиотеки: pynput, pyobjc

Для punto_llm.py дополнительно:
- Ollama с TinyLlama или другой легкой моделью

## Известные ограничения

- Односимвольные слова обрабатываются с особой осторожностью
- Короткие слова (2 символа) требуют точного совпадения в словаре
- Слова из `exceptions.txt` никогда не исправляются
- Во время быстрой печати исправление может конфликтовать с новыми символами
